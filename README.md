## Aufbau dieser Lerndokumentation

Pro Unterrichtsblock gibt es ein Verzeichnis `TAG-x` mit den drei vorgegebenen Unterverzeichnissen:

| Verzeichnis | Inhalt |

| `AUFGABEN` | Arbeitsaufträge, Lösungen, Produkte und die Challenge |
| `REFLEXION` | Selbstreflexion zum Unterrichtsblock |
